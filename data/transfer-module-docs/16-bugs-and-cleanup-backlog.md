# Bugs & Cleanup Backlog — Transfer Module

> **What this is:** A consolidated, deduplicated, engineer-actionable backlog of correctness bugs, data-integrity risks, UX-misleading behaviors, tech-debt, and hardening gaps across the Transfer module. Every item below is sourced **directly** from the per-page documentation files `01-transfer-dashboard.md` … `15-jobwork-dashboard.md` in this folder (primarily their "Gotchas" sections, plus correctness/dead-code/data-integrity notes called out elsewhere in those docs). Nothing here is invented; `file:line` references are preserved from the source docs where given.
>
> **How to read it:** Items are grouped by severity (🔴 first). Cross-page patterns that recur are collapsed into a single row listing all affected pages. Stable IDs (`BUG-xx`, `UX-xx`, `CLN-xx`, `HRD-xx`) let you reference an item in commits/tickets. A per-page coverage appendix at the end confirms nothing was dropped.
